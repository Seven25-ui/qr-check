      One-time setup: free Cloudinary storage

      A QR code can't hold a photo, so the image is uploaded and the QR holds its link. Anyone with the link can see the image.

      1. Make a free account at cloudinary.com.
      2. Settings, then Upload, then Add upload preset. Set Signing mode to Unsigned and save.
      3. Paste your cloud name (on the dashboard) and the preset name below.
